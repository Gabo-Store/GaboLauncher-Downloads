# Descargas oficiales de GaboLauncher

Instaladores publicados por GaboStore. El código de la aplicación y los datos de licencias no se almacenan en este repositorio.

## Mac · versión inicial de pruebas

- **Apple Silicon (M1, M2 y posteriores):** elige el archivo `arm64.dmg`.
- **Mac con procesador Intel:** elige el archivo `x64.dmg`.
- Requiere **macOS 13 Ventura o posterior**. Abre el DMG y arrastra GaboLauncher a Aplicaciones.
- Activa con una licencia **PC** disponible. Se mantiene un equipo por licencia; para cambiar de equipo solicita el restablecimiento al administrador.

Los instaladores de Mac tienen firma ad hoc, sin certificado Developer ID ni notarización de Apple. macOS puede impedir la apertura de aplicaciones de un desarrollador no identificado. Esta edición debe probarse antes de ofrecerla como versión estable para clientes. No es necesario desactivar Gatekeeper y el launcher no lo desactiva.

Instalar el launcher en Mac no convierte los juegos de Windows. Los `.exe` requieren un entorno compatible (Wine instalado y configurado por el cliente); la compatibilidad varía por juego y hardware. Los juegos nativos de Mac pueden importarse a la biblioteca.

Descarga los instaladores desde **Releases**. Los archivos SHA256 permiten verificar que la descarga coincide con la publicada.
